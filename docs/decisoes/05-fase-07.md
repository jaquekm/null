Sempre `.jpg` (não preserva PNG/WebP original) — simplicidade, aceitável porque é só uma miniatura de grade, nunca a imagem mostrada em tela cheia.
- **Miniatura é sempre melhor esforço, nunca bloqueia o upload real:** gerar (`generateThumbnail`) e enviar a miniatura podem falhar por qualquer motivo (formato que o navegador não decodifica, rede) sem que isso afete o anexo principal — `thumbnail_path` só fica nulo, a UI cai pro arquivo original.
