## Por que dividido (01/10)

`docs/decisoes.md` passou de 240 KB — mesmo motivo da divisão de `docs/PROGRESSO.md` (ver lá): a ferramenta de publicação no GitHub desta sessão não aceita um arquivo tão grande numa chamada só (~55–80 KB de limite prático). A divisão aqui não é por fase exata (o arquivo original intercalava decisões de fases diferentes num texto corrido só, por data) — são 7 partes sequenciais, cada uma cortada numa borda de seção (nunca no meio de uma entrada `###`), na ordem cronológica original. Nenhum conteúdo mudou, nenhuma entrada foi reclassificada — só a divisão em arquivos. Quando `07-fase-10.md` crescer demais, continue a numeração (`08-...md`) em vez de deixar ele crescer sem limite de novo.
